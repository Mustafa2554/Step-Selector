# Step-Selector

A modern, responsive, and beautifully styled multi-step component built with **React (useState)** and pure **CSS**. This project is a great beginner-friendly practice exercise for understanding state management, conditional styling, and component reusability in React.

---

## 🔗 Live Demo
- **Live Website:** [Click Here to View Live Demo](https://step-selector.vercel.app/)

---

## ✨ Features

- **Interactive Step Navigation:** Switch seamlessly between steps using **Next** and **Previous** buttons with automatic looping.
- **Dynamic Content:** Updates the step message dynamically based on the current active step index.
- **Visual Progress Indicators:** Highlight active steps using smooth transitions, scaling effects, and custom glowing gradients.
- **Fully Responsive Design:** Optimized for desktops, tablets, and mobile devices using CSS Flexbox and media queries.
- **Modern UI Styling:** Styled with smooth gradients, customized button hover effects, and clean typography.

---

## 🛠️ Tech Stack

- **React (v18+)** – Component-based UI structure and `useState` hook for state management.
- **JavaScript (ES6+)** – Logic handling and array manipulation.
- **CSS3** – Custom styling, gradients, box shadows, transitions, and responsive layout.
